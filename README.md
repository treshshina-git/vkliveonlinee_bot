# VK Live Telegram Bot

Телеграм-бот для получения списка онлайн-стримов категории "Чат Рулетка" из VK Video Live.

## Railway Variables

```env
TELEGRAM_BOT_TOKEN=...
VK_CLIENT_ID=...
VK_CLIENT_SECRET=...
```

## Запуск локально

```bash
pip install -r requirements.txt
python bot.py
```

## Команды

```
/start
/online
```
